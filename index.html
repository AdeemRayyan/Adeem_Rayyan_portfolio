Projects I've Created

A collection of projects I've built while learning and exploring web development. Each project represents a new challenge, a skill I've improved, and an idea I've brought to life.

Positivus: Agency Landing Page

A responsive landing page for a digital marketing agency, built with HTML and CSS during my SMIT project. Includes a hero section, client logos, services, and call-to-action buttons.

Saylani IT Training: Responsive Landing Page

A fully responsive landing page inspired by Saylani IT Training, built with HTML and CSS during my SMIT course. Features a navigation bar, hero section, embedded video, and course sections that adapt smoothly across desktop, tablet, and mobile screens using CSS media queries.

Saylani Login Page: Figma to HTML & CSS

A login page recreated from a Figma design using HTML and CSS, focusing on pixel-accurate layout. Features a split-screen layout with a styled sign-in form, email and password fields, and social login buttons.

OLX Clone: Online Marketplace Homepage

A pixel-focused clone of the OLX marketplace homepage built with HTML and CSS. Features a navigation bar, location and search bar, promotional banner, category icons, and product listing sections for items like bikes and properties, all laid out with a clean card-based design.

A dark-themed services page built with HTML and CSS, featuring a clean header with navigation and a contact button, plus a grid of service cards with icons, headings, descriptions, and call-to-action links.

Personal Portfolio Website

A fully responsive personal portfolio built with HTML and CSS, featuring a glowing animated navbar, hero section, about and skills sections, and a project showcase. Includes a mobile hamburger menu and smooth scrolling for a clean experience on every screen size.
